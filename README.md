# Yasmi — AI, Machine Learning & Python

A single-page editorial portfolio for Yasmi, a teacher associated with the Diploma in Artificial Intelligence field. The motion-led composition uses oversized typography, restrained blue and paper tones, concept diagrams and scroll reveals, inspired by the supplied reference recording without reproducing it.

## Run locally

```sh
npm install
npm run dev
npm run typecheck
npm run build
```

## Edit the portfolio

`src/app/App.tsx` contains the page sections and content. Replace the explicitly bracketed placeholders for educational background, experience, teaching approach, and contact details only with information Yasmi has supplied and approved. Demonstration examples are clearly labelled and should not be presented as completed personal work. The CSS and responsive layouts are in `src/styles.css`.

Motion is scroll-triggered and respects `prefers-reduced-motion`. Navigation responds to scroll direction and includes a mobile menu.
